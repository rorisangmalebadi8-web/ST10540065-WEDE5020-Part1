## Project Overview
This project is a website built for **Reeh Flex**, a South African streetwear clothing brand. Reeh Flex currently has no dedicated website and relies on a WhatsApp Business catalogue to showcase products and take orders. This project develops a proper website to give the brand a searchable, professional, and always-available online storefront.

The project is built across three parts:
- **Part 1 — Building the Foundation:** Project planning, research, and HTML structure for 5 core pages.
- **Part 2 — Designing the Visuals:** CSS styling and responsive design.
- **Part 3 — Adding Functionality and SEO:** JavaScript interactivity, form validation, SEO, and deployment.

## Website Goals and Objectives
- Move Reeh Flex's product catalogue off WhatsApp onto a searchable website.
- Increase brand visibility and reach beyond existing WhatsApp contacts.
- Provide a professional enquiry and contact channel for sales, sponsorship, and general questions.

## Key Features and Functionality
- **Homepage (index.html):** Hero image, brand tagline, featured products, brand story snippet.
- **About Us (about.html):** Brand history, mission, vision, and target audience.
- **Products (products.html):** Full catalogue organised by capsule collection, with images and pricing.
- **Enquiry (enquiry.html):** Form for product, availability, and sponsorship enquiries.
- **Contact (contact.html):** WhatsApp, email, Instagram, business location, PAXI delivery information, and a general contact form.
